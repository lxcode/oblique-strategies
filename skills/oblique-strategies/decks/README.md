# Decks

One card per line. Lines starting with `#` are comments.

`draw.py` looks in `~/.config/oblique-strategies/` (or `$XDG_CONFIG_HOME/oblique-strategies/`) first,
then in this directory. It uses `eno.txt` if found, else `engineering.txt`.
Pass `--deck <name>` to pick another file.

The original Eno/Schmidt deck is not bundled.
Transcribe your own copy into `~/.config/oblique-strategies/eno.txt`.
